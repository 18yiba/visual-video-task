# Windows v0.3.1：独立安装包

本次安装包版本按用户要求设为0.3.1；2026-10-12修正版输出至`dist/windows-v0.3.1-v3-ui`。默认打开v3实验控制台，v1/v2与Demo/正式通过旧协议快捷方式保留。内置Python运行环境和bcigo-sdk 1.0.2，安装包版本不改变协议标识或历史记录。视频材料另行复制，真实设备需现场联调。

新BrainCo采集直接保存32导EDF，按CH01→CH32含IO，单位uV、量程±375000 uV、高通0.16 Hz，低通和陷波未知。历史NPY、行为、状态与续跑路径保留原样；保存结束后另建立独立EDF/BIDS交接目录。每段连续记录用稳定UUID封装，开始菜单交接入口可处理旧记录和重试。

- 交接包包含小写 EDF、BIDS事件/通道/元数据、公司 `session.json`、原始文件哈希和离线校验状态；不包含原始状态、视频或行为源文件。
- 平台8位被试编号与范式代码据实配置；新EDF使用采集时设备快照，具体硬件型号仍未知。旧NPY转换仍需私有型号、滤波和量程配置，不猜测历史设备设置。
- EDF保留真实样本数、采样率和通道顺序，不拼接断流、不补零、不重采样或截幅。新EDF量化步长约11.44 uV，交接逐字节复制；旧float32记录保留。
- 格式校验、EEGQC评分、上传和入库回执分开；格式通过不代表设备或信号质量已经验收。
