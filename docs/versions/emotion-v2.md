# 视频 EEG 与情绪评分 V2 实验说明

版本日期2026年9月15日。保持45个固定Session及全部11,087段材料不变，增加普通视频喜好、内容抽查与其后的疲劳自评，将情绪评分改为七级。

## 被试阅读说明

请自然观看视频并聆听声音，保持舒适坐姿，尽量减少说话和大幅头动，正常眨眼即可。
普通视频结束后，请判断是否喜欢：F不喜欢，J喜欢。部分普通视频随后出现关于刚才内容的选择题，按1–4或A–D作答。
内容题下一页，请判断此刻的精神状态：F未感到明显的精神疲劳，J已感到明显的精神疲劳。
请按当前感受回答，不以题目答对、答错为依据。

情绪视频后依次评价情绪感受与唤醒程度，两项均按数字1–7作答，主观评价没有正确答案。
所有问题均不限时。短休息默认2秒，空格提前继续；长休息按F继续，按J保存退出。
需要停止时按Esc并告诉主试。S将视频放回待播队列，之后仍要完整观看。

## 参数与页面顺序

| 类型 | 自然播放结束后的页面 |
|---|---|
| 普通视频未抽中 | 喜好F/J → 短休息 |
| 普通视频被抽中 | 喜好F/J → 内容选择题 → 疲劳F/J → 短休息 |
| 情绪视频 | Valence 1–7 → Arousal 1–7 → 短休息 |

默认视频前注视1.5秒。内容题后直接进入疲劳页，中间不显示反馈或休息。

| 主观问题 | 原文与锚点 |
|---|---|
| 喜好 | 总体而言，您是否喜欢刚才这段视频？F不喜欢；J喜欢 |
| 疲劳 | 请判断您此刻的精神状态。F未感到明显的精神疲劳；J已感到明显的精神疲劳 |
| 效价 | 请评价刚才这段视频带给您的主观情绪感受。1非常不愉快；4中性；7非常愉快 |
| 唤醒 | 请评价刚才这段视频引起的情绪唤醒程度。1非常平静／几乎没有被激活；4中等；7非常激动／强烈被激活 |

内容题继续使用完整版视频题库，仅考查紧前一个普通视频，不对情绪视频出内容题。
每组9道，目标约第10、20……90分钟净视频；在目标附近随机绑定一个有题的普通视频，通常相差不到约2分钟。
抽查计划依被试和保存种子生成一次，写入session_state。不会在第600秒强制打断视频。
计时基于首次队列的普通及情绪视频时长，不包含评分与休息。实际退出、重播、跳过会改变后续实际间隔，仍保留原题目与视频绑定，不重新抽签。

45组每组净视频约90.13–90.23分钟。普通7,949段，情绪3,138段，正中负各1,046。
每组69或72段情绪视频，对应138或144次情绪评分；普通视频每段另有一次喜好，每组另有9道内容题和9次疲劳自评。
以上作答与休息额外增加到场时间，没有90分钟强制截止。

## 合并记录 2：FATIGUE_BINARY_RATIONALE.zh-CN

# 当前精神疲劳二分类的措辞与依据

本实验使用一个**研究自编、受文献启发的即时主观精神疲劳二分类条目**，不是已验证量表的官方中文版或诊断工具。
本次检索未确认有可直接照搬、经验证且适用于本视频EEG任务的中文F/J二分类单题。不要把多级疲劳量表的效度直接赋予本题。

## 页面原文与编码

题干：**请判断您此刻的精神状态。**

- F：未感到明显的精神疲劳。编码 `fatigued=0`。
- J：已感到明显的精神疲劳。编码 `fatigued=1`。

不限时，无正确答案。措辞避免口语化的“累不累”，明确询问当前状态、精神维度和“明显疲劳”的主观边界。
“未感到明显”不表示绝对没有任何疲劳。该边界由被试判断，不是临床或EEG阈值。
主试统一解释：“请根据此刻的精神疲劳感选择最符合的一项；不以刚才题目答对或答错为依据。”
不改问“想不想休息”，因为休息意愿、兴趣和疲劳不是同一变量；也不将困倦直接等同于精神疲劳。

## 文献支持的范围

1. van Hooff ML et al. 2007. *How fatigued do you currently feel? Convergent and discriminant validity of a single-item fatigue measure.* Journal of Occupational Health, 49, 224–234. [原始研究](https://pubmed.ncbi.nlm.nih.gov/17575403/)，[DOI](https://doi.org/10.1539/joh.49.224)。研究支持对当前疲劳使用简短单题进行反复自评。本题借鉴“当前状态、直接自评”的原则，不沿用其原量尺，也不声称其效度结果适用于本二分类。
2. Yang CM, Wu CH. 2005. *The situational fatigue scale: a different approach to measuring fatigue.* [原始研究](https://pubmed.ncbi.nlm.nih.gov/16047510/)。该研究将疲劳与完成活动所需内部资源的主观状态联系起来，并检验情境疲劳量表。本任务限定精神疲劳；不是完整SFS量表。

二分类满足本协议降低作答负担的要求，但会损失疲劳程度信息。正式分析应称“自报明显精神疲劳的有无”，不称客观疲劳等级。
建议先做少量被试理解检查并记录解释口径；尚未完成本条目的信效度验证。

## 固定位置与分析注意

普通视频 → 喜好二分类 → 若被抽中则内容题 → **紧接疲劳页** → 短休息。
内容题与疲劳页间不插入休息、正确性反馈或新刺激。这个固定顺序便于执行，但答题经历可能影响自报状态，解释结果时应保留这一顺序信息。
只分析 `completed=True` 的最终观看尝试；部分作答和退出均保留。题干、按键映射、协议版本和测量名称写入日志。

情绪视频仍采用效价与唤醒两维，本版改为1–7，中心锚点4，两端为1和7。
这是量尺版本变化，不能把旧1–9与新1–7原始分数直接混合，也不能仅把旧分数机械改写成新分数。
