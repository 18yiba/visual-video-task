# v3：情绪视频 EEG 与行为评分分开

v0.3.4安装版及最新源码的EEG阶段在播放情绪视频时，自动使用UGREEN Camera 4K录制1080p/30帧无声面部影像；“全部视频”和“仅情绪视频”均适用，普通视频和独立行为重播不录制。录像与session_state.json同目录，文件依次为“编码_facial.mp4”“编码_facial_02.mp4”等，已有文件不覆盖；录像覆盖刺激起止且时长不短于材料与实际播放后才提交完成。摄像头故障或校验失败停止并保存进度，当前视频保留待重播。软件时间戳与EEG事件关联，不代表硬件级曝光同步。开始菜单提供EMOTIV与博睿康两个设备入口，均支持录像；旧v0.3.1安装包不包含此功能，详见[面部录像说明](../operations/FACIAL_RECORDING.md)。

正式EEG采集使用平台已有8位字符串被试编号，保留前导零；控制台不预填示例编号。平台范式代码默认 `EMOVID-20261008`（全部视频及仅情绪视频，2026-10-11用户确认），每段启动时连同平台编号保存到采集metadata快照；旧原编号只可通过私有 `eegqc.local.json` 的 `participant_map.v3` 显式映射，不改写原状态编号。

原始EDF保存后自动另存独立 `data/eegqc/recording-<UUID>/` 单记录BIDS交接包：含32导小写EDF、通道/事件/信号JSON、公司 `session.json`，忽略规则为 `**/session.json`。每段新采集使用新UUID，重试使用原UUID；官方离线校验通过后才标记PASSED。独立行为重播的评分保留原行为CSV和状态，不写入此前EEG包，不产生额外EEG或修改封存包。人工评分、上传及最终数据库回执由EEGQC完成；详见[交接说明](../operations/EEGQC_HANDOFF.md)。

“视频范围”可选“全部视频”或“仅情绪视频”。仅情绪模式只播放原固定Session内的情绪视频，不播放普通视频，不做普通喜好、内容抽查或疲劳题；注视、休息、EEG同步及情绪行为评分仍沿用。仅情绪模式独立保存到 `data/sourcedata/v3_emotion_only`，不转换或覆盖全部视频模式的进度；采集、评分和进度检测须选择同一视频范围。命令行增加 `--emotion-only`。

双击 `run_emotion_v3.bat` 打开控制台：同一页选择EEG采集或行为评分，填写被试编号和Session，并选择全屏或窗口。EEG阶段点击“检测EEG连通性”，成功后“开始实验”；行为阶段无需设备检测。v3用户入口已移除Demo/Dummy模式，仅使用正式配置；命令行 --demo 和 --dummy-eeg 也会拒绝启动。v1/v2主启动页保留原样；BAT带命令行参数时仍可直接启动原v3命令。

点击“检测完成进度”查看该被试全部Session的采集完成视频数、情绪EEG已保存数及行为评分数；当前Session显示两条进度条，总览显示完成Session数及可继续评分数。填写编号、实验结束时自动刷新；点击表格行选择Session。进度只读取原状态与已保存EEG，不创建、修改或转换记录；缺失EEG的情绪视频不计入可评分/已完成行为。身份、协议或固定成员不匹配时停止启动并提示核对。

设备检测在独立进程运行，窗口保持响应；检测完成后设备停止，不写入被试数据。启动采集时自动再次核验数据流，不再显示编号填写页或设备选择页；采集的原时间同步、看门狗和保存流程不变。实验运行时锁定控制台，须在实验窗口按Esc保存退出，随后自动刷新进度，不能通过关闭控制台强制终止采集。

v3沿用v2固定视频、题库、普通视频喜好F/J、9次内容抽查及紧接的疲劳1–5。情绪视频采集阶段只完整播放并记录EEG，不出现情绪评分；保存退出后，评分入口不连接设备、不启动EEG、不发送硬件marker。效价与唤醒的原题干、锚点、顺序和1–7评分原样复用。

行为阶段按已保存观看顺序重播可评分的情绪视频；每段选择1 原速、2 1.5倍速、3 2倍速，音频同步变速并保持音高，然后评分。倍速只用于行为重播，采集播放器及EEG时间同步不变。Esc保存退出；未完成的行为视频续跑时重播，并重新回答两页，已完成评分不重做。

每个Session新增 `emotion_video_list.csv`，列出情绪视频及EEG已保存/评分已完成状态；此表用于查看，放行评分仍核对 `session_state.json` 的完整播放、增长的样本索引及对应已保存EEG文件/metadata。未完成、跳过、没有样本或缺失EEG文件的视频不能评分。程序不以此证明信号质量；仅外部录制而无本地EEG文件时不放行。

正式配置 `video_eeg/config/video_emotion_v3_config.yaml` 继承v2设备参数和材料路径，新增独立阶段标记。新正式数据存 `data/sourcedata/v3`，目录结构、原子保存与EEG导出沿用原程序；不转换或覆盖v2记录。EEG采集完成状态独立于行为完成状态，行为完成查看情绪清单及 `emotion_rating_log.csv`。行为时间沿用原时间字段，评分样本索引为空，附 `behavior_eeg_recorded=false` 和重播速度；原视频的采集时间、样本索引、EEG文件、事件均不改。

命令行同样支持：

```powershell
.venv/Scripts/python.exe -m video_eeg.experiment.emotion_v3_runner --emotion-stage eeg
.venv/Scripts/python.exe -m video_eeg.experiment.emotion_v3_runner --emotion-stage ratings
```

模拟窗口验证：`scripts/validation/smoke_emotion_v3.py`；不代表真实BrainCo硬件验收。
