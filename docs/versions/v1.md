# visual-video-task v1：17个Session，视频EEG

这是实验室早期完整版题库协议。统一入口run_experiment.bat中选择“visual-video-task v1”，再选择Demo或正式。配置video_eeg/config/video_legacy_17_config.yaml，成员清单session_manifest.csv，均保持原文与哈希，不重新分组。

## 被试任务

自然观看普通视频并聆听声音。没有情绪视频、喜好页、疲劳页或效价/唤醒评分。被抽中的视频自然结束后，对刚才视频内容选择一项，按1–4或A–D，不限时。内容题采用原完整版题库；不改为数学计算。

共v1（17个Session）、7949段正式视频，单段5–60秒，每组18次随机内容抽查。每组平均净视频约177.5分钟；答题和休息另计，无固定到点截断。各组固定成员、组内顺序随机并持久保存；S跳过的未完成视频之后重播，不重新抽题。

注视默认1.5秒，视频后短休息默认2秒；连续净观看30–45分钟附近出现休息页。休息页F继续、J保存退出，Esc保存中止；按键与原协议保持一致。完整视频和其绑定回答一起提交，未答完的任务续跑重播。

## 原被试如何继续

保留data/video_question_complete_runs/<被试>/session_XX整个目录；统一入口输入相同被试编号和Session，发现该协议旧进度后继续写原根目录。新被试默认data/sourcedata/v1。不要把v1状态作为v2进度。

题库是complete_questions_20260908/question_bank.json，7993题，其中正式视频有3条未配题（5728、6722、6883）；抽查只能选有题视频。ready=2779，generated_unreviewed=5214；自动生成不等于独立复核，来源、review状态和哈希必须保留。

## 材料、采集与质量

v1（17个Session）只需普通母库；正式默认BrainCo SDK真实采集、1000Hz。Demo为10段合成短片和3道练习题，模拟EEG，不使用被试正式状态。普通母库共7996文件，固定正式清单用7949段；不要为了目录整齐改名或删掉其他原始视频。

已增加共享的断流看门狗；这不会改变v1（17个Session）协议和题库。持续无样本会停止并保存，阻抗变红本身不触发此阈值。安装、视频路径见[README](../../README.md)，数据/故障文件见[恢复说明](../operations/EEG_AND_RECOVERY.md)。
