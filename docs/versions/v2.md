# 视频 EEG 与情绪评分 V2 实验说明

版本日期2026年9月15日。保持45个固定Session及全部11,087段材料不变，增加普通视频喜好、内容抽查与其后的疲劳自评，将情绪评分改为七级。

## 被试阅读说明

请自然观看视频并聆听声音，保持舒适坐姿，尽量减少说话和大幅头动，正常眨眼即可。
普通视频结束后，请判断是否喜欢：F不喜欢，J喜欢。部分普通视频随后出现关于刚才内容的选择题，按1–4或A–D作答。
内容题下一页显示“当前您的疲劳程度是？”，按数字1–5作答；1几乎不疲劳，5非常疲劳、完全无法继续观看。完整五档描述见下方。
请按当前感受回答，不以题目答对、答错为依据。

情绪视频后依次评价情绪感受与唤醒程度，两项均按数字1–7作答，主观评价没有正确答案。
所有问题均不限时。短休息默认2秒，空格提前继续；长休息按F继续，按J保存退出。
需要停止时按Esc并告诉主试。S将视频放回待播队列，之后仍要完整观看。

## 参数与页面顺序

| 类型 | 自然播放结束后的页面 |
|---|---|
| 普通视频未抽中 | 喜好F/J → 短休息 |
| 普通视频被抽中 | 喜好F/J → 内容选择题 → 疲劳1–5 → 短休息 |
| 情绪视频 | Valence 1–7 → Arousal 1–7 → 短休息 |

默认视频前注视1.5秒。内容题后直接进入疲劳页，中间不显示反馈或休息。

| 主观问题 | 原文与锚点 |
|---|---|
| 喜好 | 总体而言，您是否喜欢刚才这段视频？F不喜欢；J喜欢 |
| 疲劳 | 当前您的疲劳程度是？1几乎不疲劳；5非常疲劳，完全无法继续观看 |
| 效价 | 请评价刚才这段视频带给您的主观情绪感受。1非常不愉快；4中性；7非常愉快 |
| 唤醒 | 请评价刚才这段视频引起的情绪唤醒程度。1非常平静／几乎没有被激活；4中等；7非常激动／强烈被激活 |

内容题继续使用完整版视频题库，仅考查紧前一个普通视频，不对情绪视频出内容题。
每组9道，目标约第10、20……90分钟净视频；在目标附近随机绑定一个有题的普通视频，通常相差不到约2分钟。
抽查计划依被试和保存种子生成一次，写入session_state。不会在第600秒强制打断视频。
计时基于首次队列的普通及情绪视频时长，不包含评分与休息。实际退出、重播、跳过会改变后续实际间隔，仍保留原题目与视频绑定，不重新抽签。

45组每组净视频约90.13–90.23分钟。普通7,949段，情绪3,138段，正中负各1,046。
每组69或72段情绪视频，对应138或144次情绪评分；普通视频每段另有一次喜好，每组另有9道内容题和9次疲劳自评。
以上作答与休息额外增加到场时间，没有90分钟强制截止。

## 当前疲劳五点评分：措辞、记录与恢复

题干：**当前您的疲劳程度是？**

| 分数/按键 | 描述 |
|---|---|
| 1 | 几乎不疲劳 |
| 2 | 轻度疲劳 |
| 3 | 中等疲劳，但不需要额外努力就能继续观看 |
| 4 | 较重疲劳，需要付出一定努力才能继续观看 |
| 5 | 非常疲劳，完全无法继续观看 |

按用户指定的五档描述，以1–5连续编号，描述疲劳及继续观看所需努力；不使用“清醒”“对抗睡眠”等困倦判断。它是本实验自编的主观疲劳条目，不是原困倦量表的缩短版，也不声称沿用其信效度。

数字1–5及数字小键盘均可作答。F/J仍用于喜好和长休息，不能回答新疲劳题；0、6–9忽略。先释放内容题按键，再接受疲劳页的新按键，避免把上一页的答案误记为疲劳分数。不限时，不显示正确性反馈，不因高分自动停止；Esc保存并退出。

van Hooff等人的[即时疲劳单题研究](https://pubmed.ncbi.nlm.nih.gov/17575403/)为询问当前疲劳状态提供参考。本实验使用用户指定的中文题干与五档锚点，未验证其在本任务中的信效度，不能直接继承该研究或截图量表的效度结论。主试统一说明：根据当前疲劳感选择，不以刚才内容题答对或答错为依据。

### 数据和版本识别

新量尺标识为 `research_adapted_fatigue_5point_v1`，`fatigue_rating`为整数1–5，`fatigue_scale_min=1`、`fatigue_scale_max=5`、`fatigue_scale_type=five_point`。题干和所有选项文字写入行为日志；事件162/163保持原编号，附带量尺和响应值。metadata也保存量尺信息。未回答的项为空，不写0分，不生成二分类fatigued字段。

已开始并保存二分类或七点疲劳协议的Session保持原量尺续跑，下一个新Session使用五点评分。旧记录保留原fatigued=0/1或fatigue_rating=1–7，不换算成1–5。新记录保存fatigue_rating=1–5、fatigue_scale_min/max、fatigue_measure、fatigue_wording及完整fatigue_key_map；分析时须按量尺分开。未知或不匹配的状态仍拒绝续跑，不通过改哈希强行迁移。

普通视频→喜好F/J→若被抽中则内容题→立即疲劳页→短休息。固定视频、抽查绑定、情绪效价/唤醒七点评分均保持原样。未完成的尝试保留但不提交，恢复后完整重播视频并重答。仅分析completed=True的最终尝试，并区分疲劳量尺版本。
