## 发布目录与清理范围

源码发布白名单增加三个**零字节**占位文件：

```text
stimuli/videos/.gitkeep
data/video_question_complete_runs/.gitkeep

```

发布检查会拒绝非空占位文件；视频只进入单独的 GitHub Release，不写入 Git 源码树。
