# v3 情绪视频面部录像

Windows v0.3.2安装包与同版本GitHub源码均包含此功能；开始菜单分别选择“视频EEG v3 EMOTIV设备入口”或“视频EEG v3 博睿康设备入口”。旧v0.3.1安装包不包含录像功能。

v3 EEG采集播放情绪视频时自动录制 UGREEN Camera 4K；普通视频、独立评分重播和v1/v2不录制。录制规格为1920×1080、30帧/秒、H.264 MP4，无麦克风声音。Windows需允许桌面应用访问摄像头，并关闭占用设备的应用。设备缺失、同名歧义、无法打开或规格不支持时停止，不自动换摄像头或降低规格。

## 文件与续跑

文件保存在实际续跑的session_XX目录，与session_state.json同级。材料文件名去扩展名作为编码，首次为“编码_facial.mp4”，重复观看为“编码_facial_02.mp4”、_03等，超过99次继续递增。编号结合日志及现有文件分配，已有文件和中断片段不覆盖，不增加子目录。

每个MP4对应一个同名.timestamps.csv，记录帧序号、帧到达软件时的perf_counter时间、捕获管线PTS、编码PTS和相对情绪视频开始的时间。facial_recording_log.jsonl记录编号、attempt、文件、设备规格、单调时钟/Unix时间映射、视频起止事件及EEG样本索引、验证结果和错误。逐帧行在关闭时写出；强制断电可能只有MP4片段及reserved日志，不能将其视为完整录像。

## 同步与完成条件

摄像头先稳定输出并至少预录0.5秒，再允许播放；结束后至少后录0.5秒。刺激起止取PsychoPy刷新回调中现有EEG事件的单调时钟时间。摄像头帧时间是FFmpeg处理并向Python报告帧时的软件观察值，含USB、驱动、解码、线程调度和日志缓冲延迟，不代表曝光时刻；编码PTS保存独立的媒体时间，不用补帧或修改帧率拉长录像。

完整观看必须通过全文件解码、帧数与严格递增时间检查，首尾帧覆盖视频前后各0.5秒，解码时长同时不短于材料核验时长及实际播放时长，软件观察帧间隔不得超过1秒。失败时停止当前运行并保存已有EEG和进度，视频保持待重播。Esc、S、EEG故障和播放异常的片段标记为不完整，不要求达到完整材料时长。分片MP4有助于保留异常中断内容，但不能保证断电时所有帧已经落盘。

录像是独立原始数据，不代替EEG、行为日志和session_state，不自动加入BIDS/EEGQC包；备份时复制整个Session。历史完成状态不变，不补造旧视频录像。面部影像、时间文件和录制日志均不得进入源码发行。

## 验收

开发回归可运行 `python scripts/validation/smoke_emotion_v3.py --emotion-only --facial-synthetic`：真实PsychoPy窗口、模拟EEG、合成1080p/30帧录像；此参数只属于测试脚本。移除--facial-synthetic后使用真实UGREEN摄像头，EEG仍为模拟数据。

正式使用前在目标电脑检查长视频、磁盘负载、重复播放、拔线后的保存续跑，并用摄像头可见的屏幕闪烁测量同步偏差。软件通过不能替代真实摄像头或EEG硬件验收，不能宣称硬件级曝光同步。
