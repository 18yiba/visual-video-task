以下1.0.4内容保留作为历史安装、迁移与数据保全说明，当前新增32导EDF/EEGQC流程见[交接说明](EEGQC_HANDOFF.md)。

# Windows 1.0.2：本机路径、原数据迁移与移动硬盘断开

下载Release中的VisualVideoTask-Setup-Windows-x64.exe，复制到实验室本机后双击安装。支持Windows 10/11 x64，自带Python和依赖。默认安装到当前用户的 %LOCALAPPDATA%/Programs/VisualVideoTask，不再继承旧安装器可能设置的移动硬盘安装位置。采集不需要互联网；设备所需局域网连接仍须保留。

## 从已安装的1.0.1更新到1.0.2（片尾修复）

1. 正常按空格退出报错页，等数据保存完成，关闭视频EEG程序。备份整个当前被试目录；保留失败尝试及所有时间戳采集目录。
2. 从本仓库Release下载1.0.2安装包，或从移动硬盘复制到实验室本机再运行。保持原安装位置，无需卸载、重复迁移或重新复制视频。
3. 更新只替换程序文件。原本机设置、固定材料、题库快照、已有data及session_state保留；不要删除state或改完成标记。
4. 主试先用独立测试编号检查声音、评分和真实设备数据流，再用原被试编号、v2、原Session续跑。该未完成视频会重播，然后依次进入效价和唤醒评分；已完成片段不应重播。
5. 本次重复暴露会影响情绪反应，应在实验记录中注明次数及原因；保留失败attempt供分析，不能假称被试首次观看，也不能事后补造评分。

1.0.2只对[全库核验清单](VIDEO_EOF_AUDIT.md)内SHA256完全匹配的原片处理1–2帧片尾差异，末帧保持到各自原标称截止，不改变视频、分组、题库、评分规则或正式状态哈希。更早解码失败、其他文件或文件内容变化仍按原保护中止。trial_log新增decoder_eof_compatibility说明本次是否应用兼容处理。

**已知不完整材料涉及v2 Session：20（6076.mp4）、24（2693.mp4）、33（6241.mp4）。** 这些Session需要完整原片，安装更新不能补回缺失视频。1.0.2会在正式开始前提示停止；其他Session不因这些文件被全局阻止。

新版拒绝把运行程序、视频、协议快照和保存根目录放到用户所在盘以外的盘符、网络目录或junction中。本实验室即要求C盘。选择video_materials的上级目录也会查找真正含完整视频的叶目录，不能仅凭“目录存在”接受路径。

## 从1.0.0更新

1. 用原入口正常结束并保存采集，备份整个被试目录，包括EEG、进度、行为日志和题库快照。不在采集中升级。
2. 暂时接回之前实际用来保存新记录的移动硬盘。把安装包复制到本机后运行，旧程序和原数据不删除。
3. 第一次运行1.0.1会重新设置本机路径。选择“迁移内容题版v1到本机”，选择实际使用的旧目录（直接包含video_eeg）。若此前绑定错了硬盘上的目录，先从该目录恢复已写入的记录；不要凭空用另一个题库替代旧配置。
4. 自动读取旧17组配置，复制正式及Demo配置、固定清单、题库和排除清单到用户目录中的独立快照；普通和情绪记录的已知保存目录逐文件复制并核对SHA256。只接受当前17组视频内容题配置，保留题库及状态哈希。若目录同时含旧算术配置和有效内容题配置，选择内容题配置；只有算术配置则停止。历史算术数据原件保留，不能转换后混入当前实验。
5. 已经位于本机目标数据根目录内的记录原位保留。其他来源放入独立imported目录，绝不覆盖现有文件。复制期间源文件变化、空间不足或校验失败会停止，原设置不切换。
6. 同一被试若在多个本机候选位置存在进度，正式运行停止并列出冲突；不自行挑选“最新”、合并或覆盖。原始路径保留在迁移回执中供核对。
7. 启动页显示实际普通视频路径和新数据根目录；已有v1默认选v1。先用全新测试编号运行Demo，再完成真实设备短测和续跑位置核对。
8. 正常退出程序及安装器，然后安全移除移动硬盘。再次启动新EXE，确认路径仍为本机C盘，再投入正式采集。

迁移对源数据只读。续跑本机副本会正常更新其session_state及行为日志，因此不能把“迁移不覆盖原件”理解为“之后所有文件都不变”。复制哈希一致也不能证明之前强制拔盘没有造成不完整采集；有异常必须保留原记录核查。

## 没有正式材料时

可在材料选择取消后明确选择先做Demo。正式实验必须选择本机材料并通过逐文件哈希核验；不会回退到移动硬盘或自动联网下载。首次核验需读取全部视频，迁移数据也需要本机空闲空间和读写时间。

## 旧目录哪些文件仍在使用

配置迁移成功后，新EXE不再从原旧程序目录读取Python、venv、配置或题库。实际依赖为安装目录自身、上面的本机视频、本机数据，以及 %LOCALAPPDATA%/VisualVideoTask/migration/迁移编号/profile 中的配置快照。用户设置及日志同样保存在本机 %LOCALAPPDATA%/VisualVideoTask。

从开始菜单运行：
- “视频EEG文件盘点”：输出“当前依赖逐文件.csv”和“旧目录逐文件清单.csv”，逐个列出完整路径、分类及保留结论。移动硬盘断开时保留已有清单，不把未读取到的文件当作不存在。
- “视频EEG归档缓存”：只对明确识别、重新核验的Python/pytest缓存，复制并校验后移入桌面video下的_archive；生成恢复清单。不会递归删除目录，不归档采集数据、视频、配置、环境或未知文件。
- “视频EEG检查硬盘占用”：输入盘符，例如E:，报告可读取进程的打开文件、程序位置和工作目录；不自动杀进程，也不能枚举全部内核句柄。

报告在 %LOCALAPPDATA%/VisualVideoTask/reports。旧源码和环境不再是新版运行依赖，但仍是旧程序回退资源；材料metadata、reports及分组审计文件不属于刺激播放文件，却有来源和复核用途。“新版不用”不等于“没有价值”。只提供视频库副本时，不能断言实验室其余旧目录都能删除。

## 故障与验证边界

系统提示设备正在使用时，不要强制拔出。检查安装器、旧入口、终端、数据查看工具和占用报告；只关闭确认属于自己的程序。新版所有正式运行路径均在本机，但不能替其他程序保证磁盘可拔。

本版包含模拟EEG、数据迁移及恢复测试；真实设备、驱动、声音和物理触发时延仍须实验室短测。安装器没有商业代码签名，Release提供SHA256。后续卸载不主动清理独立的本机采集数据、迁移快照或源目录。

## 构建

运行源码环境安装器后，用.venv/Scripts/python.exe执行scripts/build_windows_release.py，传入--iscc编译器路径。使用源码白名单构建，不发布实验室配置、迁移回执、数据或真实视频。

当前v1/v2保留视频内容选择题，不运行旧算术判断题。Demo也使用内容题练习；不要把历史算术目录当作当前实验目录。
