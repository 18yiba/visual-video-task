# 视频解码错误：全库核查、片尾修复与1.0.3材料排除

对正式v2的11,087条视频逐条顺序解码至EOF，发现26条已独立核验的1–2帧片尾差异（情绪13、普通13），以及3条明确不完整的普通视频。其余11,058条声明帧数与本次解码计数相同。

核查日期2026-09-19。OpenCV逐帧grab到EOF；所有计数异常另用FFmpeg -xerror -err_detect explode完整解码并统计原始输出帧数。所有异常文件都核对对应发布清单SHA256。哈希相同只证明字节相同；不能证明发布原件一定完整。计数相同也不等于在每台实验室电脑完整播放验收。

**当前1.0.3已获授权从v2排除三条不完整的普通视频，其余11,084条保留。无需寻找原片才能开始这三组。**详见[最小更新与旧进度处理](V2_MATERIAL_REMOVALS.md)。共享母库及v1历史协议保留。

## 采集与分析记录

1.0.2片尾修复不改视频、题库、固定分组、评分规则或已有协议哈希。1.0.3另外叠加三条明确排除规则；原清单与协议哈希仍保留用于历史兼容，有效清单另行发布。保存并关闭后更新即可，已有1.0.1无需重复迁移。失败/退出的当前片按原规则重播与评分；原来成功完成的其他片保留。重复暴露可能改变情绪反应，须登记次数和原因，保留旧attempt，不补造缺失评分。

自动测试、旧/新播放器对比、真实窗口评分/续跑和模拟EEG断流验证用于软件回归；真实实验室EEG设备和声音/显示时延仍未验收。
