# 从旧 17 组更新到 Emotion EEG v1：离线最小操作说明

适用：实验室电脑已有能正常运行的旧 17 Session 视频 EEG 范式，不能联网。
新协议是 **45 个 Session + 每段情绪视频后两页 1–9 评分**，不是之前的 34 组内容题更新包。

## 本次硬盘交付：推荐一键部署

硬盘 `video/实验室离线更新_情绪45组_20260914` 已放好解压后的代码包、`00_一键部署到实验室电脑.bat` 和说明。
在实验室退出范式并备份旧数据后，接上硬盘，双击00并选择旧程序目录。
它自动把代码和硬盘上的3,138个情绪视频复制到旧程序内的新文件夹，支持复制中断后继续。
之后依次运行新增文件夹内的01检查、02Demo、03真实设备短测。

实验室原 `video_materials` 只有普通 EEG 视频也可以：继续复用它；情绪视频由硬盘补齐到新增目录，
不修改原材料目录。选的是包含 `video_eeg` 和旧入口的程序目录，不是 `video_materials`。
下面的手动步骤仅用于备用。

## 硬盘只带两样

1. `视频EEG_45组情绪协议_离线更新包.zip`：新版完整运行代码、45 组清单和检查/启动入口，不含数据或环境。
2. 当前已验证情绪库里的整个 `selected` 文件夹，共 3,138 个视频、9.87 GB（约 9.19 GiB）。
   本机来源：`E:\video\video_materials\formal_v1\emotion_video\selected`。
   不带 parquet、下载缓存或整套 eMotions；普通视频库先复用实验室原有的。

不要把本机整个 Desktop/video 覆盖实验室电脑。不要复制 `.venv`、`runtime`、被试 `data` 或旧状态。

## 每台电脑按顺序做

1. 等正在进行的实验结束、数据保存后退出。先复制备份该机旧 `data` 及实际采集目录；不能剪切。
2. 找到原程序目录（包含 `video_eeg` 和旧启动 BAT；通常还有 `.venv`）。
   桌面快捷方式不一定在这个目录：右键旧快捷方式“打开文件所在的位置”并核对 BAT 调用路径。
3. 解压 ZIP，把里面**整个** `_video_eeg_emotion_v1_update` 文件夹放进旧程序目录。
   只新增文件夹，不散开覆盖旧代码。出现覆盖已有文件提示时取消，先核对位置。
4. 把硬盘上的**整个 `selected` 文件夹**复制进新增目录的 `emotion_video` 文件夹。
   文件和子文件夹名称全部保留。建议复制到电脑本地磁盘，确保新代码、情绪视频和数据盘合计有足够剩余空间。

```text
原程序目录/
  .venv/                       原环境不动
  video_eeg/                   原代码和设备配置不动
  data/                        已采数据不动
  原启动入口.bat               继续旧17组时仍用它
  _video_eeg_emotion_v1_update/  只新增此文件夹
    01_先检查.bat
    02_Demo.bat
    03_正式45组.bat
    离线更新操作说明.md
    video_eeg/
    scripts/
    emotion_video/
      selected/
        positive/excitation/*.mp4
        positive/relaxation/*.mp4
        neutral/neutral/*.mp4
        negative/fear/*.mp4
        negative/sad/*.mp4
        negative/tension/*.mp4
```

5. 双击 `01_先检查.bat`。程序只读旧配置，复用该机旧 Python 3.12、普通视频路径和设备参数，
   检查代码包完整性、环境依赖、全部视频 ffprobe 以及情绪视频 SHA256。
   核验需要一段时间，完成后会显示报告；看到 `OFFLINE EMOTION CHECK PASSED` 才开始正式测试。
   Demo 可在尚未复制情绪库时独立先试；正式实验必须先通过完整材料核验。
6. 双击 `02_Demo.bat`，使用模拟 EEG 检查窗口、中文、键盘、两页评分、退出和数据保存。
   四段合成练习中三段有评分，共六次评分；不需要真实 EEG。
7. 接好 EEG、检查阻抗和耳机声音，双击 `03_正式45组.bat`。
   先用**单独测试编号**短测，检查真实 EEG、视频声音、评分和退出写盘，确认后再采新被试。
   首先在一台电脑验证，再给其他电脑重复上述步骤。

不需要先安装 34 组版本，也不要在离线电脑重新运行联网安装器。
本次升级没有增加运行依赖，但未知旧版本可能缺组件；检查失败不能保证直接运行，需带回报告准备匹配的离线依赖包。

## 旧被试和新数据

**已按旧 17 组开始的被试，继续旧入口和原方案。** 45 组重新安排了视频并增加评分，
不能将旧 Session 编号或 `session_state.json` 复制过去续跑；也不能把旧17组当作新45组的前17组。
若确实要让已开采被试改变方案，需要另行确定实验设计和新起点，程序不会自动迁移。

新正式数据保存在：`原程序目录/data/video_emotion_eeg_runs/protocol_emotion_v1/`。
新 Demo 保存在：`原程序目录/data/video_emotion_eeg_runs/offline_demo/`。
旧数据全部留在原处；备份时把新旧采集输出都包含进去。
新协议约90分钟是净视频时长，评分和休息另计，实际实验时间更长。

## 检查报错或回退

旧程序不受更新包影响，关闭新版后重新用旧入口即可。保留新增目录和新数据，不需要删除任何文件。
把更新目录里的 `check_report.txt`，以及 `logs/emotion_material_audit.json`（若有）复制回联网电脑排查。
不要为解决错误覆盖旧环境或旧被试状态。

若提示缺普通视频，只补报告中缺失的文件；先不要搬整个普通库。文件时长或校验不符时，先核对来源，
不要擅自用本机视频覆盖正在进行的旧研究材料。若新协议必须用不同版本，可另外放一套兼容材料并单独配置。

默认读取旧 `video_eeg/config/video_config.yaml`；若存在旧 `run_complete_formal.bat`，
读取其 `video_ready_config.yaml`。其他自定义入口可在更新目录新增 `OLD_CONFIG.txt`，
写入旧配置的绝对路径或相对原程序目录的路径，再检查报告确认设备配置和视频目录正确。
更新包寻找原程序或其上一级的 `.venv/Scripts/python.exe`，不移动旧环境。

**不要直接把 GitHub 新源码随便放进子目录后双击普通入口。** 普通入口默认寻找自身 `.venv`，
这个离线包的三个编号入口专门负责复用旧环境和设备设置。
