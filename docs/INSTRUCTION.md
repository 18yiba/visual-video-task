# 视频 EEG 实验指导语

本实验只采集观看视频期间的脑电数据，不进行主观评分。正式材料固定划分为 34 个 Session；每个
Session 的视频集合由 manifest 决定，Session 内播放顺序随机但会保存到断点状态。

每个视频先显示注视点，然后完整播放。每个正式 Session 随机抽查 18 次，问题针对刚结束的视频，
用 1、2、3、4 或 A、B、C、D 选择答案，不限时，不显示正确答案。未抽中的视频直接短暂休息。
被抽中的视频在作答后短暂休息；按空格可提前继续。答题时 Esc 退出，续跑会先重播该视频再提问。

连续净观看约 30–45 分钟后会显示较长休息页面。休息可以停留任意时间，按 F 选择“继续”，或按
J 选择“退出”保存并显示当前 Session 的 duration progress。每个视频结束后的短暂休息会自动完成。

按 S 只中断当前视频 attempt，视频仍会在后续重新从头播放；按 Escape 为紧急安全退出。两种情况
均记录事件、保存 checkpoint，已中断的视频不计入完成进度。
