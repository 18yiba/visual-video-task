# 利用硬盘最快更新到情绪协议 V2

适用于实验室只有17组、34组，或已安装45组九级评分版本的电脑。使用新增文件夹，复用原Python、设备配置和视频，不覆盖原程序或已采数据。

## 在这台电脑上带走什么

移动硬盘交付目录：`E:\video\实验室离线更新_情绪V2_20260915`。
带走整个目录，其中包括00部署BAT、部署PS1、`_video_eeg_emotion_v2_update`代码包与操作说明。

如果目标电脑还没有情绪视频，还需硬盘上保持这套现成材料：
`E:\video\video_materials\formal_v1\emotion_video\selected`，共3,138段、约9.87 GB。
不需要再次复制普通视频，不用复制parquet、下载缓存、其他电脑的data或Python环境。
硬盘换成F/G等盘符后，部署脚本按自身相对位置找材料，不要求固定E盘。

## 到实验室后的最短步骤

1. 结束正在进行的实验并正常保存；备份旧data。不要在采集中更新。
2. 双击硬盘交付目录的 `00_一键部署到实验室电脑.bat`。
3. 选择**原程序主目录**，其中有 `video_eeg/config/video_config.yaml` 和原启动BAT；不要选video_materials，也不要选新旧更新包内部。
4. 程序在旧目录内新增 `_video_eeg_emotion_v2_update`。旧环境、旧配置、旧数据不被替换。
5. 在新文件夹依次双击 `01_先检查.bat` → `02_Demo.bat` → 完成真实设备短测 → `03_正式45组.bat`。
6. 把03入口创建为清楚标注“V2 七级 喜好 抽查 疲劳”的新快捷方式。旧快捷方式供旧协议继续使用。

## 哪些视频会复制

部署器优先查找目标电脑：根目录本机 `emotion_library.local.json` 指定位置、旧 `_video_eeg_emotion_v1_update/emotion_video`、旧目录的`emotion_video`、项目旁标准`video_materials/formal_v1/emotion_video`。
若找到3,138文件的selected目录，新增一个路径配置直接复用，**不再复制约9.87 GB**。该快速数量检查不是完整验收，01仍逐项核对SHA256和ffprobe。
若未找到，则从硬盘标准位置复制3,138个文件到新更新包的`emotion_video/selected`。复制支持中断续传，不删除旧目标、不使用镜像删除。
如果情绪库在未自动识别的其他目录，可在复制前把旧项目的本机`emotion_library.local.json`指向该emotion_video目录。

原普通视频按旧配置复用。01会核验全部11,087段材料及情绪文件校验值，耗时取决于硬盘速度；请让检查完成，不以“复制完成”代替“材料通过”。
完成检查后应可拔掉传输硬盘；若你手动把材料路径指向外接盘，则运行期间必须保持该盘连接。

## 已有数据与版本

V2新数据写到旧主目录 `data/video_emotion_eeg_runs/protocol_emotion_v2`。
原17组、34组、九级45组的已有状态均保留。九级45组原数据位于protocol_emotion_v1，不能直接作为V2进度续跑。
新协议改了量尺和任务，旧被试默认继续原协议；如研究设计确需中途切换，须单独登记版本与切换Session，不能把旧分数或状态转换后冒充V2记录。

更新包复用现有Python3.12，不联网安装。缺依赖或设备配置异常时，保留检查报告，不覆盖旧环境。
运行中不要用Excel占用日志文件，不要编辑session_state、题库快照或视频文件名。
