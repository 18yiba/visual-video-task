# 视频 EEG 与情绪评分 V2 实验说明

版本日期2026年9月15日。保持45个固定Session及全部11,087段材料不变，增加普通视频喜好、内容抽查与其后的疲劳自评，将情绪评分改为七级。

## 被试阅读说明

请自然观看视频并聆听声音，保持舒适坐姿，尽量减少说话和大幅头动，正常眨眼即可。
普通视频结束后，请判断是否喜欢：F不喜欢，J喜欢。部分普通视频随后出现关于刚才内容的选择题，按1–4或A–D作答。
内容题下一页，请判断此刻的精神状态：F未感到明显的精神疲劳，J已感到明显的精神疲劳。
请按当前感受回答，不以题目答对、答错为依据。

情绪视频后依次评价情绪感受与唤醒程度，两项均按数字1–7作答，主观评价没有正确答案。
所有问题均不限时。短休息默认2秒，空格提前继续；长休息按F继续，按J保存退出。
需要停止时按Esc并告诉主试。S将视频放回待播队列，之后仍要完整观看。

## 参数与页面顺序

| 类型 | 自然播放结束后的页面 |
|---|---|
| 普通视频未抽中 | 喜好F/J → 短休息 |
| 普通视频被抽中 | 喜好F/J → 内容选择题 → 疲劳F/J → 短休息 |
| 情绪视频 | Valence 1–7 → Arousal 1–7 → 短休息 |

默认视频前注视1.5秒。内容题后直接进入疲劳页，中间不显示反馈或休息。

| 主观问题 | 原文与锚点 |
|---|---|
| 喜好 | 总体而言，您是否喜欢刚才这段视频？F不喜欢；J喜欢 |
| 疲劳 | 请判断您此刻的精神状态。F未感到明显的精神疲劳；J已感到明显的精神疲劳 |
| 效价 | 请评价刚才这段视频带给您的主观情绪感受。1非常不愉快；4中性；7非常愉快 |
| 唤醒 | 请评价刚才这段视频引起的情绪唤醒程度。1非常平静／几乎没有被激活；4中等；7非常激动／强烈被激活 |

内容题继续使用完整版视频题库，仅考查紧前一个普通视频，不对情绪视频出内容题。
每组9道，目标约第10、20……90分钟净视频；在目标附近随机绑定一个有题的普通视频，通常相差不到约2分钟。
抽查计划依被试和保存种子生成一次，写入session_state。不会在第600秒强制打断视频。
计时基于首次队列的普通及情绪视频时长，不包含评分与休息。实际退出、重播、跳过会改变后续实际间隔，仍保留原题目与视频绑定，不重新抽签。

45组每组净视频约90.13–90.23分钟。普通7,949段，情绪3,138段，正中负各1,046。
每组69或72段情绪视频，对应138或144次情绪评分；普通视频每段另有一次喜好，每组另有9道内容题和9次疲劳自评。
以上作答与休息额外增加到场时间，没有90分钟强制截止。

首次配置、所有YAML参数、材料路径和设备选项见[README](../README.md)。

Demo用4段合成练习素材，覆盖1次喜好、1道练习内容题、1次疲劳和6页情绪评分，模拟EEG，不能算正式采集。
检查本次协议、被试编号及Session，先材料检查、Demo，再真实设备短测。已有17/34组或45组九级评分被试继续原协议。

口播：“接下来请自然观看视频并听声音。普通视频后判断是否喜欢；偶尔会询问刚才视频的内容，答完后请报告当前精神状态。情绪视频后，先评愉快程度，再评情绪反应强弱，各按1到7。主观题没有对错，也不限时。休息按屏幕提示操作。不舒服或想停止时按Esc并告诉我。”

## 保存与恢复

新数据根目录 `data/video_emotion_eeg_runs/protocol_emotion_v2`，按被试和Session保存。
普通视频必须完成喜好，以及其可能绑定的内容题和疲劳题，才一起提交完成；情绪视频必须完成两页评分才提交。
任何作答页中止时保存已答部分，视频仍未完成；同编号同Session续跑会完整重播视频并重答整套页面。
已提交后在短休息中止，不重播已完成视频。旧状态不覆盖，不自动迁移到V2。

| 文件 | 内容 |
|---|---|
| session_state.json | 权威状态、随机队列、抽查计划、每次完整或部分attempt |
| question_bank_snapshot.json | 原题库快照；SHA256不匹配时拒绝混用 |
| trial_log.csv | 视频观看尝试、实际播放时长和完成标记 |
| ordinary_behavior_log.csv | 每个普通视频尝试的喜好、可能的内容题及疲劳 |
| video_liking_log.csv | 普通视频行为记录视图，liked 0/1 |
| video_question_log.csv | 被抽中视频的尝试，含题目、选项、正确答案、响应及题源复核状态 |
| fatigue_log.csv | 已进入疲劳页的尝试，fatigued 0/1及题干与按键映射 |
| emotion_rating_log.csv | 情绪评分；rating_scale_min=1、rating_scale_max=7、protocol_version=emotion-v2 |
| rest_log.csv | 已发生的长休息 |
| 采集时间戳子目录 | 连续EEG、events、metadata、EEG分段说明 |
