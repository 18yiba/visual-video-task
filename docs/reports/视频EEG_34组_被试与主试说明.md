# 34组视频 EEG 实验说明

被试与主试合并版 · 2026年9月14日

本说明适用于34个 Session 的视频观看与内容抽查协议。用于向课题组汇报，并统一被试说明和主试操作。已进入这一协议的被试继续使用原入口与原进度；融合情绪评分的45组协议另有说明。

## 第一部分 被试阅读说明

### 实验任务与流程

实验会在你观看视频时记录脑电。请自然、认真地观看屏幕和聆听声音。部分视频结束后会出现一道关于刚才内容的选择题，请根据实际看到的内容作答。这里不要求评价情绪，也不需要做计算题。

每段视频前显示注视点，视频结束后进入内容题或短休息。每组有18次内容抽查，答题不限时。每组视频净时长约89分钟，答题、休息及准备另计；实验不会在90分钟时强制结束。实验可跨次到场完成。

### 按键与休息

| 页面或情况 | 操作 |
| --- | --- |
| 内容抽查 | 按1–4或A–D选择一项 |
| 短休息 | 默认2秒；空格可提前继续 |
| 长休息 | F继续；J保存并退出本次实验 |
| 感到不适或需要停止 | 按Esc并告知主试 |

观看时尽量保持坐姿稳定，减少说话、咬牙及大幅头动，正常眨眼即可。休息时按主试指导放松。若视频卡住、声音异常或出现错误提示，请通知主试，不要反复按键或自行重启。

退出后已完成记录会保留。下次使用相同编号及同一组继续；尚未完整完成的视频与其内容题会重新呈现。

## 第二部分 主试参数与启动

| 项目 | 34组协议 |
| --- | --- |
| 正式材料 | 7,949段普通视频；母库共7,996段 |
| 固定分组 | 34组；每组233–235段，涵盖五档时长 |
| 净视频时长 | 每组88.35–88.94分钟；均值88.76分钟 |
| 播放顺序 | 组成员固定；每名被试组内随机并保存 |
| 内容题 | 每组18次；绑定视频自然结束；不限时 |
| 注视与休息 | 注视1.5秒；短休息2秒；约30–45分钟净观看后提示长休息 |
| 正式入口 | run_video_legacy_34.bat 或 run_video_formal.bat |
| 练习入口 | run_video_demo.bat；10视频与3次抽查 |
| EEG默认配置 | BrainCo SDK直连；1000 Hz |

净时长按旧34组清单统计，不含答题与休息。Session是固定材料组，可分次到场完成。

### 首次部署与每日开始

新电脑完整解压代码，双击 install_lab_env_uv.bat 安装。普通母库通过 download_materials.bat 下载到 stimuli/videos，或复用项目旁 video_materials/formal_v1/videos。已有健康环境可复用。不要改名或重新分配正式视频。

主试确认设备连接、阻抗、声音、可写空间及被试编号，先用Demo熟悉流程，再做真实设备短测。正式启动核对 Session 为1–34，且使用真实采集配置。旧17组被试仍用17组原入口，不在本版中直接续接。

### 标准化口播

“接下来请自然观看视频并听声音。偶尔会询问刚才视频的内容，请按1到4选择最符合的一项，答题不限时。休息时按屏幕提示操作。如果不舒服或想停止，请按Esc并告诉我。请保持坐姿稳定，不需要刻意憋住眨眼。”

## 第三部分 记录恢复与验收

### 记录保存在哪里

正式根目录为 data/video_question_complete_runs/protocol_34sessions，按被试和Session保存。session_state.json是恢复依据；trial_log.csv记录观看尝试，attention_log.csv记录抽查和作答，EEG分段目录保存连续脑电、events与采集metadata。不要覆盖状态、题库快照或被试目录。

自然播放结束且对应题目完成后，视频才计为完成。S将当前视频放回待播队列，供主试处理临时播放问题；不用于免看。Esc中止时保留未完成任务，重启使用同一编号与Session，不重新抽题。

### 题库与结果解释

完整版题库有7,993道题，覆盖7,946个正式视频；5728、6722、6883三个视频保留播放，但不作为抽查目标。2,779题有原复核记录，5,214题已生成并通过结构检查、尚未独立逐题复核。题目生成状态不能等同于人工复核通过。

内容题正确率反映这一任务的行为表现，不能直接代替脑电信号质量。当前程序没有依据某个通道阻抗变红自动终止的阈值；明确设备异常可能触发退出，静默断流则不保证自动停止。主试需持续关注BCIGo状态。

### 结束与异常检查

正常退出后，核对被试编号、完成进度、trial及抽查记录，并确认EEG和事件文件已写出。错误时记录时间、完整报错、当前视频及设备状态，保留现场日志，排查后同编号续跑。不能仅凭重新打开成功就判定断连期间的脑电有效。

### 验证范围与说明来源

本说明按当前代码、34组清单、题库覆盖审计和主试手册整理。软件流程与模拟EEG已有验证；真实设备连接、声音、物理触发时延和每台实验机的采集质量仍须现场验证。

结构参考用户提供的图片EEG、情绪图片评分、情绪视频评分三份被试与主试合并说明。各参考程序的量表、按键和设备参数不适用于本协议。详细资料见仓库 docs/OPERATOR_MANUAL.zh-CN.md 与 SESSION_34_AND_LABEL_AUDIT.zh-CN.md。
