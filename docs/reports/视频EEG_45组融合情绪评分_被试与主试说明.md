# 45组融合情绪评分视频 EEG 实验说明

被试与主试合并版 · 2026年9月14日

本说明适用于最新 Emotion EEG v1 协议：在连续脑电采集中交错播放普通视频与情绪视频，并在情绪视频后完成两项九级评分。用于课题组汇报、被试说明及主试操作。新协议共45组，使用独立进度与数据目录。

## 第一部分 被试阅读说明

### 实验会怎样进行

请自然观看视频并聆听声音。部分视频结束后直接进入休息，部分视频后依次出现两道评分题。请按观看刚才视频时的真实感受作答，没有正确答案，也不需要猜测研究者期待的分数。

| 评分维度 | 含义与锚点 |
| --- | --- |
| 情绪效价 Valence | 评价愉快或不愉快；1非常不愉快，5中性，9非常愉快 |
| 唤醒程度 Arousal | 评价情绪被激活的强弱；1非常平静，5中等，9非常激动 |

两题独立判断。感到不愉快但情绪很强烈时，效价可以低、唤醒可以高；感到愉快而放松时，效价可以高、唤醒可以低。每页按数字1–9直接选择，不限时；松开按键后再回答下一页。

### 时长与操作

每组净视频约90分钟，不包括评分、休息及准备，实际到场时间会更长。短休息默认2秒，空格可提前继续；长休息出现后按F继续，按J保存退出。需要停止时按Esc并告知主试。

观看与评分时尽量保持坐姿稳定，减少说话、咬牙和大幅头动，正常眨眼即可。出现疲劳、不适、声音或画面异常请及时告知主试。未完成的视频或两页评分，下次继续时会完整重播并重新评分。

### 呈现与评分

普通：注视 → 视频 → 短休息。情绪：注视 → 视频 → Valence → Arousal → 短休息。默认注视1.5秒、短休息2秒。新协议不再安排每组18次内容抽查。两页评分均用数字键1–9，按键立即提交；不显示视频情绪标签、文件名或路径。

固定清单决定组成员，初次开始时为被试与Session生成并保存播放队列。普通视频随机；情绪视频按普通视频累计时长均匀插入并交错效价。每组普通视频包含五档时长。首次顺序避免连续三段同效价情绪视频，跳过或恢复后的局部顺序可能变化。

约30–45分钟实际净观看后，在视频及评分结束的边界提示长休息。部分观看和重播计入休息时钟，评分与休息不计入；完成进度则按完整提交的视频计算。90分钟不是强制截止。

情绪视频来自官方 eMotions 的最终核验集合，单段5–60秒且不转码。原始标签按效价合并，Relaxation归入Positive；公开metadata缺少可靠逐视频平台字段，因此不声称平台平衡。

## 第三部分 主试部署与现场操作

### 联网新电脑

完整解压GitHub源码，双击 install_lab_env_uv.bat，再运行新Demo。Demo自动生成4段合成视频，包含3个情绪trial和6页评分，使用模拟EEG，不能用作正式数据。此集成程序不需要另开Node评分服务。

普通库用 download_materials.bat 获取，或复用项目旁 video_materials/formal_v1/videos。情绪库须另复制最终 emotion_video/selected 的3,138段原始文件，保留六类子目录与文件名；默认放在项目旁 video_materials/formal_v1/emotion_video 下。GitHub源码和普通母库Release均不包含情绪视频本体。

放置后双击 check_emotion_materials.bat 检查11,087段材料及情绪SHA256。自定义路径和官方来源索引见 docs/EMOTION_EEG_PROTOCOL.zh-CN.md。材料审计通过后，还需确认声音、设备连接、阻抗与真实EEG写盘。

### 实验室只有旧17组且离线

使用硬盘离线交付包的 00_一键部署到实验室电脑.bat，选择该机旧程序目录。更新以新增文件夹方式复用健康环境及普通视频，另复制约9.87 GB情绪视频，不覆盖旧数据。按包内顺序执行01材料核验、02模拟Demo、03正式45组。无需先把17组升到34组。

### 每次正式采集

核对本次采用新协议，选择真实采集配置并登记被试编号及1–45的Session。默认BrainCo SDK直连、1000 Hz。旧17或34组被试继续原协议，不能把原session_state.json复制到新协议。确认被试理解两个评分维度后再开始。

### 标准化口播

“接下来请自然观看视频并听声音。有些视频后会询问你的感受，请先评价愉快程度，再评价情绪反应强弱，各按1到9作答，没有对错、也不限时。休息按屏幕提示操作。感到不舒服或想停止时，请按Esc并告诉我。”

被试询问应该给几分时，只解释量表含义，不提示答案。S仅用于将有临时播放问题的视频放回待播队列，不用于减少正式材料。

## 第四部分 数据恢复与质量核对

### 连续记录与数据位置

EEG在视频、评分和休息间持续记录。正式数据根目录为 data/video_emotion_eeg_runs/protocol_emotion_v1，按被试与Session保存；断点恢复会生成新的采集分段。

| 文件 | 用途 |
| --- | --- |
| session_state.json | 权威恢复状态；禁止手动覆盖 |
| trial_log.csv | 普通与情绪视频观看尝试、完成及中止 |
| emotion_rating_log.csv | 两项评分、反应时、标签、事件时间和部分attempt |
| events与连续EEG文件 | 阶段事件、样本索引、脑电与采集metadata |

只有视频自然结束并完成两页评分才提交情绪trial。视频、效价页或唤醒页中止时保留部分attempt，续跑完整重播并从效价重答。分析选取completed=True的最终attempt，不将部分评分当作完成记录。

新marker为150/151情绪视频起止、152/153效价呈现及响应、154/155唤醒呈现及响应、156/157短休息起止；普通视频132/133。样本索引须结合对应EEG分段使用，不能当作跨续跑的全局索引。

### 异常与现场检查

当前没有按通道阻抗变红自动停止的阈值。后台明确设备异常可触发退出并尝试保存；仅停止送样本但未抛异常时，不保证自动停止。events不是逐时刻信号质量日志，主试仍须监视BCIGo及设备电量。

实验运行中避免用Excel占用日志。若CSV被占用，新版会尝试另存.recovered时间戳文件；磁盘权限或空间不足仍需处理。错误时保留完整报错、时间及日志，排查后同编号同Session恢复，结束时核对EEG、事件、评分与完成状态。

### 验证范围与参考

已验证模拟EEG写盘、评分与续跑；真实硬件和物理时延仍待现场验证。结构参考用户提供的三份说明，参数以本程序为准。详情见docs中的EMOTION_EEG_PROTOCOL.zh-CN.md与EMOTION_RATING_RATIONALE.md。九级文字评分不等同于完整图形SAM量表。
